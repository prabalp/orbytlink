name: monthly-reconciliation
trigger: schedule, 1st of month 09:00
version: 4
permissions:
  - stripe: read
  - hubspot: read
  - sheets: write
approval: finance-lead
---

# Monthly reconciliation

1. stripe.list_payouts for last month
2. hubspot.search_invoices for each payout
3. Match by amount and date, tolerance 1%
4. agent: review mismatches and explain each one
   using [[refund-policy]]
5. sheets.append_rows to "Close / {{month}}"

> Compiled from 20 runs. If a step fails, the agent
> takes over and proposes an update.
---
name: refund-policy
description: How we decide refunds and who signs off
---

# Refund policy

- Under $500: approve if the order shipped
  less than 30 days ago.
- Over $500: ask finance-lead before refunding.
- Duplicate charges: refund at once, then tell
  the customer which charge was kept.
- Always log the reason on the ticket.

> Written by the ops team. Used by 3 workflows.

A few things to know.

Do I need to switch agents?

No. OrbytLink connects to MCP compatible clients, including Claude, Cursor and Codex. Keep using the agent you prefer.

What can I connect?

Connect MCP servers and HTTP APIs. OrbytLink holds the credentials and exposes the enabled tools through one endpoint.

Does my agent get my API keys?

No. Credentials are encrypted on the server. OrbytLink attaches them when it calls a connected service.

Can I review a workflow before it runs?

New workflow drafts start disabled. An admin reviews the steps and enables the workflow before the team can use it.

Are the example timings measured results?

No. The monthly close example illustrates how the process could evolve. Its times and costs are not a product benchmark.

What is available in early access?

The page labels capabilities still in early access, including tailored toolsets, automatic fallback and version history. Create a workspace to explore the connected tools available today.
