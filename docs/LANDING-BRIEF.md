# Landing page redesign

Scope: landing/index.html, landing/redesign.css, landing/redesign.js. Visitor mode: persuade. The existing console and legal text are outside the redesign. Original snapshot: landing/previous/.

## Direction contract

THESIS: Show how one completed task becomes reusable work. Replace the repeated dark marketing panels with a legible instruction sheet.

OWN-WORLD: Manrope, near-white paper, charcoal text, and substantial lilac fields. Rounded controls, crisp process connectors and restrained product demonstrations.

STORY: Connect an agent to existing tools, do a real job, inspect what can be reused, and request early access. Illustrative runs remain explicitly labelled.

FIRST VIEWPORT: Large two-line left-aligned headline, supporting copy below, action at the opposite edge, then a full-width lilac process example. Its button switches between the first run and the reusable outcome. On mobile the action precedes the demonstration.

FORM: Workflow instruction sheet. seed:a5b79bd861b4efb3. Built directly in code under the user's redesign authorization; no visual comp was approved.

FINISH: Independent review, desktop/mobile functional checks, and scoped token documentation in docs/LANDING-DESIGN.md and .impeccable/design.json. No new raster assets.
